# Joanna Boby – Personal Portfolio

Welcome to my personal portfolio website!
This website showcases my skills, projects, and information about me in a simple and responsive design.

## About the Project

This portfolio was created using **React and Vite**. It is designed to present my work and skills in a clean and user-friendly way.

The website includes:

* Home section
* About Me section
* Skills section
* Projects section
* Contact section
* Project filtering
* Responsive design
* Light and dark mode

## Technologies Used

* **React**
* **Vite**
* **JavaScript**
* **HTML**
* **CSS**

## Design

The website uses a **blue and orange colour theme** with contrasting backgrounds and text for better readability.

It is also designed to work on:

* Desktop
* Tablet
* Mobile

## Getting Started

To run the project on your computer:

### 1. Install the dependencies

```bash
npm install
```

### 2. Start the development server

```bash
npm run dev
```

### 3. Open the website

After starting the server, open the local address shown in the terminal.
